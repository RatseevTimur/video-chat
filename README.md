# Video-Chat 🎥

**WebRTC + ThreeJS + React + ExpressJS + Vite**

**Demo: https://video-chat-one-delta.vercel.app/**

Интерактивное видеочат приложение с распознаванием лиц и наложением масок в реальном времени.

## ✨ Возможности

- 🎭 **Распознавание лиц** с помощью TensorFlow.js и MediaPipe
- 🕶️ **Наложение масок** (очки, солнцезащитные очки, маски) в реальном времени
- 📹 **Видеозвонки** через WebRTC (с видео и без)
- 🎨 **3D рендеринг** масок с помощью Three.js
- 🔄 **Socket.IO** для сигналинга WebRTC соединений
- 🏠 **Система комнат** как в Google Meet - создание и присоединение по ссылкам
- 👥 **Множественные участники** в одной комнате
- 🔗 **Прямые ссылки** для приглашения участников

## 🚀 Быстрый запуск

### Предварительные требования
- Node.js (версия 16+)
- Yarn или npm
- Веб-камера для тестирования

### Установка и запуск

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd video-chat
   ```

2. **Установите зависимости**
   ```bash
   # Установка зависимостей для всех компонентов
   yarn install
   
   # Или установка по отдельности
   yarn client:install
   yarn server:install
   ```

3. **Запуск в режиме разработки**
   ```bash
   # Запуск сервера и клиента одновременно
   yarn dev
   
   # Или запуск по отдельности
   yarn --cwd server dev    # Сервер на порту 4000
   yarn --cwd client dev    # Клиент на порту 5173
   ```

4. **Откройте приложение**
   - Клиент разработки: http://localhost:5173
   - Продакшн версия: http://localhost:4000

## 📱 Использование

### 🏠 Система комнат (Google Meet стиль)
1. **Главная страница** (`/`) - создание и присоединение к комнатам
2. **Создайте комнату** - нажмите "Создать комнату" для создания новой комнаты
3. **Пригласите участников** - скопируйте ссылку и поделитесь ею
4. **Присоединитесь по ссылке** - перейдите по ссылке `/room/{roomId}`
5. **Начните видеозвонок** - нажмите "Начать видеозвонок" для перехода к видеозвонку
6. **Видеозвонок в комнате** - автоматически подключается к участникам комнаты

### 🎭 Демо масок
- **Страница масок** (`/masks`) - демонстрация распознавания лиц и наложения масок

### 📞 Классический режим
- **Страница звонков** (`/call`) - интерфейс для прямых звонков по ID пользователя
- **Введите ID друга** для начала звонка
- **Выберите тип звонка**: с видео или только аудио

```

├── client/                 # React фронтенд
│   ├── src/
│   │   ├── components/     # React компоненты

│   │   └── assets/         # Изображения масок

├── server/                 # Express сервер
```

## 🛠️ Технологии

- **Frontend**: React 18, Vite, SCSS
- **Backend**: Express.js, Socket.IO
- **WebRTC**: PeerConnection для видеозвонков
- **AI/ML**: TensorFlow.js, MediaPipe Face Mesh
- **3D**: Three.js для рендеринга масок
- **Deployment**: Vercel

## 🚀 Деплой на Vercel

1. Подключите репозиторий к Vercel
2. Настройки сборки:
   - Build Command: `yarn client:build`
   - Output Directory: `client/dist`
3. Деплой автоматически настроен через `vercel.json`

## 🔧 Разработка

### Доступные команды

```bash
# Разработка
yarn dev                    # Запуск сервера и клиента
yarn --cwd client dev       # Только клиент
yarn --cwd server dev       # Только сервер

# Сборка
yarn client:build          # Сборка клиента
yarn start                 # Запуск продакшн сервера

# Установка зависимостей
yarn client:install        # Установка зависимостей клиента
yarn server:install        # Установка зависимостей сервера
```

### Переменные окружения

Создайте `.env` файл в папке `server/`:
```
PORT=4000
ALLOWED_ORIGIN=*
NODE_ENV=development
```
